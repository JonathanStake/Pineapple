5-Card Pineapple

How to put the game online so anyone can play on their own phone or computer.

Don't double-click index.html. That opens only the screen the players see, with no game behind it, and the page will tell you so. The game runs when the folder is on a web host (below) or when server.js is running on your computer (see the end of this page).

Part 1 — Put the game online (once, about 10 minutes)

You'll use two free services: GitHub stores the files, and Render runs them and gives you a web address. Neither needs a credit card for this.

  1. Unzip the download. You get a folder called pineapple. Inside it: server.js, package.json, README.md, Dockerfile, render.yaml, this page, and a folder called public.
  2. Create a GitHub account. Go to github.com/signup and sign up (free). Confirm your email.
  3. Make a new repository. Once signed in, click the + in the top-right corner and choose New repository. Type pineapple as the name. Leave everything else as it is. Click Create repository.
  4. Upload the files. On the empty repository page, find the sentence that starts “Get started by creating a new file or uploading an existing file” and click that link. Open your pineapple folder in Finder, select everything inside it (not the folder itself), and drag it onto the browser window. Wait until all the files are listed, then click the green Commit changes button at the bottom.

    If the public folder didn't come through as a folder, open it in Finder and drag index.html and engine.js in separately; when GitHub asks for a name, type public/ before the file name.

  5. Create a Render account. Go to render.com, click Get Started, and choose Sign in with GitHub. Approve the access it asks for.
  6. Create the web service. On your Render dashboard click New (top right) → Web Service. Pick your pineapple repository from the list (click Connect next to it; if the list is empty, click “Configure account” and allow Render to see the repository).
  7. Fill in the form. Most of it is already right. Check these:
    FieldWhat to put
    NameAnything, e.g. pineapple. It becomes part of your address.
    Language / RuntimeNode
    Build Commandnpm install
    Start Commandnode server.js
    Instance TypeFree
    Then click Create Web Service (or Deploy Web Service) at the bottom.
  8. Wait for “Live”. Render builds it for a minute or two and shows a log. When the status at the top says Live, your address is shown just under the service name: something like https://pineapple-x1y2.onrender.com. Open it. You should see the green table and “Open a new table”. That address is the game, permanently.

Part 2 — Play and share (every time)

  1. Open your Render address on your phone or computer. Type your name and tap Open a new table.
  2. You'll see a four-letter table code and a Copy link button. Tap it and send the link to the other players any way you like (text message, WhatsApp, Slack, email). The link already contains the code.
  3. Each player opens the link on their own phone or computer, types their name and taps Join. They appear in your lobby as they arrive. Nobody needs an account or an app.
  4. When everyone's there, tap Deal. Everyone gets five cards that only they can see; throw away one card each on the flop, turn and river; the showdown shows every hand and keeps the score. Tap Deal the next hand to keep going.

Someone who arrives mid-hand waits and is dealt in next hand. If you leave, the dealer's job passes to the next player. If a phone loses signal or the page is reloaded, it comes back to the same seat with the same cards.

If something doesn't look right

What you seeWhat it means
“This page was opened as a file…”You double-clicked index.html. Use your Render address instead (Part 1, step 8).
“Couldn't reach the game server…” or “failed to fetch”The server isn't running at that address. On Render, check the service shows Live and the Start Command is exactly node server.js.
The address takes 30–60 seconds to loadNormal on Render's free plan: the server naps after 15 minutes with nobody connected and wakes on the first visit. Tables that were open before a nap are gone; open a new one.
“No open table has the code…”The table was closed, or the server restarted. The dealer opens a new table and shares the new link.
Render says the build failedOpen the service's Settings and check Runtime is Node, Build Command npm install, Start Command node server.js. Then click Manual Deploy → Deploy latest commit.

Alternative — run it on your own Mac (same Wi‑Fi only)

Good for testing, or for a room where everyone is on the same Wi‑Fi. Players elsewhere can't reach it this way.

  1. Install Node if you don't have it: nodejs.org, the “LTS” download, then run the installer.
  2. Open Terminal (in Applications → Utilities, or search for it with Spotlight).
  3. Type cd (with a space after it), drag the pineapple folder from Finder into the Terminal window, and press Return.
  4. Type node server.js and press Return. It replies “5-Card Pineapple is listening on port 3000”. Leave this window open while you play.
  5. On your Mac, open http://localhost:3000. On other phones on the same Wi‑Fi, open http:// followed by your Mac's IP address and :3000, for example http://192.168.1.23:3000. Your IP address is in System Settings → Wi‑Fi → Details.

Over a plain http:// address the Copy link button may not reach the clipboard; the link is still shown so you can select and copy it by hand.
